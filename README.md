## 🌟 Overview

**Max Portfolio** is a lightweight, mobile-optimized 3D showroom and interactive portfolio designed for Jubayer Ahmad. Featuring procedural lighting, smooth 360-degree orbit camera damping, and spatial audio feedback, it provides an elegant showcase of production systems and technical competencies.

---

## 🚀 Key Features

* **360° Orbit Camera Controls:** Powered by `camera-controls` and `gsap` for silky-smooth transitions between overview perspectives and close-up project workstations.
* **Spatial Audio Feedback:** Integrated `howler.js` soundscapes providing tactile auditory cues upon interacting with nodes and terminal elements.
* **Lightweight Bundle Architecture:** Sub-megabyte initial JS footprint, ensuring zero frame drops even on budget smartphones and low-bandwidth connections.
* **Interactive Terminal Console:** Direct command-line interface inside the 3D canvas allowing visitors to inspect system metrics, git logs, and live production endpoints.

---

## 🛠️ Tech Stack

- **Graphics & 3D:** Three.js (v0.183), WebGL
- **Animations:** GSAP (GreenSock)
- **Audio Engine:** Howler.js
- **Camera & Interaction:** Camera-Controls
- **Build Tool:** Vite 6

## 💻 Local Development

```bash
# Clone repository
git clone https://github.com/Jubayer-AI-Studio/max-portfolio.git

# Enter directory
cd max-portfolio

# Install packages
npm install

# Run dev server
npm run dev
```
